# MASTER PROMPT — Build CGV-style Frontend (TypeScript, No `any`) on Existing BE

**Context**
- Bạn đã có Backend (Node.js + TypeScript, Drizzle + MySQL) với các module: `auth, user, movie, cinema, room, seat, showtime, booking, ticket, payment`.
- Yêu cầu tạo Frontend riêng trong thư mục `/frontend` dùng **Next.js + TypeScript**.
- Yêu cầu:
  - **Không dùng `any`**, chỉ dùng `type` thay vì `interface`.
  - Toàn bộ dữ liệu từ DB qua API BE, không truy vấn DB trực tiếp.
  - Các endpoint backend đã có (auth, movies, cinemas, rooms, seats, showtimes, bookings, payments, tickets).
  - Auth bắt buộc để giữ ghế & thanh toán.
  - Seat map endpoint: `GET /seats/rooms/:roomId/show_times/:showtimeId/seat-map`.
  - `POST /payments/intent` trả thêm `redirectUrl?: string` hoặc `qrData?: string`.
  - `GET /payments/:id` mở cho **chủ booking** để FE poll status.

## 5. HTTP wrapper
```ts
const BASE = process.env.NEXT_PUBLIC_API_BASE_URL ?? '';

export async function apiGet<T>(path: string, token?: string): Promise<T> {
  const r = await fetch(`${BASE}${path}`, {
    headers: { ...(token ? { Authorization: `Bearer ${token}` } : {}), 'Content-Type': 'application/json' },
    credentials: 'include',
  });
  const json = (await r.json()) as ApiResponse<T>;
  if (!json.header?.success || !json.data) throw new Error(json.header?.message ?? 'Unknown error');
  return json.data;
}

export async function apiPost<TReq, TRes>(path: string, body: TReq, token?: string): Promise<TRes> {
  const r = await fetch(`${BASE}${path}`, {
    method: 'POST',
    headers: { ...(token ? { Authorization: `Bearer ${token}` } : {}), 'Content-Type': 'application/json' },
    body: JSON.stringify(body),
    credentials: 'include',
  });
  const json = (await r.json()) as ApiResponse<TRes>;
  if (!json.header?.success || !json.data) throw new Error(json.header?.message ?? 'Unknown error');
  return json.data;
}
```

## 6. User Flow (giống CGV)
1. **Home** → hiển thị phim đang chiếu/sắp chiếu.
2. **Movie Detail** → trailer, mô tả, CTA “Đặt vé”.
3. **Chọn rạp/ngày/suất** → filter rạp, tab ngày, chọn giờ chiếu.
4. **Booking page (Seat Map + Combo)**:
   - Yêu cầu login.
   - Render sơ đồ ghế, chọn ghế.
   - Gọi `POST /bookings/hold`.
   - Hiển thị countdown giữ ghế.
5. **Checkout**:
   - Tóm tắt vé + combo.
   - Chọn phương thức thanh toán.
   - `POST /payments/intent` → nhận `redirectUrl` hoặc `qrData`.
   - Nếu redirectUrl → điều hướng, nếu qrData → render QR.
   - Poll `GET /payments/:id` đến khi `PAID`/`FAILED`.
6. **Done**:
   - Lấy vé qua `GET /tickets/by-booking/:bookingId`.
   - Render QR vé.
7. **Tickets**:
   - `GET /bookings/mine` → hiển thị danh sách vé của tôi.
